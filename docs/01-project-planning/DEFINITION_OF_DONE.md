# Phase I definition of done

1. Supported Python/Java file, ZIP and public GitHub acquisition produces bounded, immutable byte-preserving snapshots and manifests.
2. Traversal, links, bombs, unsafe URLs, redirects, malformed archives and excessive downloads fail with structured errors; imported code is never executed.
3. Deterministic preprocessing preserves original bytes, extracts tokens/comments/docstrings with source spans, produces separate normalized/NLP representations, warnings, duplicate links and actual statistics.
4. Versioned Pydantic contracts, PostgreSQL migration, API/OpenAPI and Celery job interfaces persist metadata and expose processing status/results/issues.
5. Licensed synthetic fixtures and automated tests cover the specified positive/negative cases; record exact commands, results and environment blockers.
6. Frontend reaches M1 only: strict build, design tokens, base/fx component showcase, accessibility and typed adapter seam. Preserve original M2–M7 requirements and explicitly report absent images.
7. Documentation and traceability reflect evidence. Completion is conditional on all mandatory Phase I checks; unrun checks remain explicit.
8. Stop at Phase I and M1. No Phase II–V implementation or frontend M2 until explicit authorization.
