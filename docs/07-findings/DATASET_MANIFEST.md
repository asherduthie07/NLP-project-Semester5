# Dataset manifest

Source: `datasets/samples/`; provenance and MIT license recorded in `datasets/README.md` and `datasets/LICENSE`. Each file's actual hash, language, parser version, statistics and issue codes are in `sample-preprocessing.json`, generated by `python -m scripts.sample_report`.

| File | Purpose |
|---|---|
| catalog.py | Module/class/method/nested docstrings, import, decimal literal call, Unicode comment |
| catalog_duplicate.py | Exact byte duplicate of catalog.py |
| Catalog.java | Class/method/imports, JavaDoc, comment and comment-like string |
| broken.py | Deliberate syntax error; tokens retained, AST unavailable warning |
| Broken.java | Deliberate syntax error; lexical records retained |
| empty.py | Empty supported Python source |
| Empty.java | Empty supported Java source; byte-identical to empty.py |
| notes.txt | Unsupported extension, recorded as ignored |

No real GitHub corpus was imported. No performance benchmark or model accuracy is implied by this tiny synthetic corpus. Additional encoding/security variations are generated by deterministic tests and are not counted as tracked corpus files.
