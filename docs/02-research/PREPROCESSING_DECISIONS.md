# Preprocessing decisions

Original representation: immutable original byte blob and SHA-256. Python honors PEP 263 encoding declarations via `tokenize.detect_encoding`; Java accepts UTF-8, UTF-8 BOM and BOM-marked UTF-16. Strict decoding rejects undecodable/binary control content. No heuristic lossy replacement or blanket ASCII conversion is used.

Parsed representation: exact decoded original, encoded to UTF-8 for Tree-sitter Python/Java. Lexical records include identifiers, language keywords, strings/characters, numbers, operators, punctuation and comments. Composite strings are atomic tokens; interpolation expressions inside an atomic string are not separately counted. Tree-sitter error recovery is explicitly signaled. Python AST identifies actual module/class/function/async-function docstrings, including nested definitions; syntax failure retains lexical tokens but marks AST docstrings unavailable. AST never evaluates expressions.

Normalized representation: optional CRLF/CR to LF only. Indentation, operators, braces, case, punctuation and literal content are preserved. Source locations always refer to the decoded original, never to the normalized view. Original raw byte offsets can differ by encoding/BOM; `utf8_start/end` explicitly refer to UTF-8 of the decoded original.

NLP representation: source-linked segments from identifiers and extracted comments/docstrings. Optional snake/camel splitting and comment delimiter/whitespace cleanup affect these segments only. Docstring segment content comes from the AST constant; its raw source span/text is also retained. Do not use this view as executable source or evidence of behavior. Stop words are not indiscriminately removed from code.

Coordinates: lines start at 1; Unicode code-point columns start at 0; spans are half-open. Tree-sitter LF-based rows are converted from UTF-8 byte columns. Source line statistics use Python `splitlines()` semantics (including Unicode line separators); they are descriptive text counts, not statement counts. Unique identifiers are distinct exact spellings across all files; duplicates are included in aggregate token/comment counts and separately reported by identical byte hashes. JavaDoc is included in comments; Python docstrings have a separate counter. Two empty files of different languages are still byte duplicates.

Java Unicode escape pretranslation is not simulated; such input gets a warning. Contextual keywords and malformed grammar recovery are lexical approximations. No Phase II semantic entity/dependency analysis is implied. Effective token caps are recorded in preprocessing configuration and included in job identity; exceeding a cap yields an explicit error with partial lexical records. Versions of grammars, Tree-sitter, Python AST interpreter and CodeAtlas tokenizer are recorded.
