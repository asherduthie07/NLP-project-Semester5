# API contracts — v1

Machine-readable evidence: checked-in `openapi.json`, generated by `python -m scripts.export_openapi`; frontend types generated with `npm --prefix frontend run contracts`. Runtime `/docs` and `/openapi.json` expose the same schemas. All operations are under `/api/v1`.

| Method and path | Contract / behavior |
|---|---|
| GET `/health` | Database readiness, scope/schema version |
| POST `/imports/files?name=...` | multipart `files`; SourceSnapshot, 201 |
| POST `/imports/zip?name=...` | multipart `file`; SourceSnapshot, 201 |
| POST `/imports/github` | GitHubImportRequest; Job, 202 |
| GET `/projects` | Project[] |
| GET `/projects/{id}` | Project |
| GET `/projects/{id}/snapshots` | SourceSnapshot[] |
| GET `/snapshots/{id}` | SourceSnapshot |
| GET `/snapshots/{id}/manifest` | ImportManifest |
| GET `/snapshots/{id}/files/{file_id}/original` | Byte-identical attachment, ETag and nosniff |
| POST `/snapshots/{id}/preprocessing` | PreprocessRequest (`{}` uses defaults); Job, 202 |
| GET `/jobs/{id}` | Job state, linked snapshot, errors |
| GET `/jobs/{id}/results` | CAIR lexical results; 409 until preprocessing result available |
| GET `/jobs/{id}/issues` | Job plus file preprocessing issues |
| GET `/jobs/{id}/statistics` | Computed PreprocessingStatistics |

Errors consistently use `ErrorResponse.error` with code/message/details/schema_version: validation 422, unsafe input 400, unsupported type 415, limits 413, missing entity 404, result state 409, queue 503, upstream GitHub failures as persisted job issues. Validation responses omit raw uploaded data and inputs. Unexpected errors log server-side without leaking internals.

Client integration: `frontend/src/data/api.ts` defines PhaseOneApi and a real Fetch adapter; `mock.ts` is explicitly empty and rejects processing. The Zustand store can swap adapters. M1 does not add an ingestion dashboard before the original shell milestone. Responses are typed, but network shape validation in the Fetch adapter is compile-time only; server Pydantic validates outbound results. Future UI adapter methods from the original spec remain planned for their milestones.
