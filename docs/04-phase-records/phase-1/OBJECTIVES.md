# Phase I objectives

Build and verify secure collection, source preservation, lexical preprocessing, versioned contracts, persistence, APIs, background work and reproducible dataset inspection. Preserve the entire frontend specification and deliver M1 alone. Acceptance criteria are defined in `../../01-project-planning/DEFINITION_OF_DONE.md`; each requirement is mapped in `../../REQUIREMENTS_TRACEABILITY.md`.

The work must report malformed/unsupported/unsafe input accurately, never execute imported code, and distinguish synthetic visual examples from measured pipeline data. Every metric in the findings comes from the real pipeline. No later academic analyzer/model/dashboard/export is part of this phase.
