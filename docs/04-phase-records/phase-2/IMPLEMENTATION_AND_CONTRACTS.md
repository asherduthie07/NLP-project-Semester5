# Phase II implementation and contracts

`analyzers/structure.py` implements Python AST and Java Tree-sitter extraction. `analyzers/exploration.py` resolves relationships, detects cycles and computes separate code/documentation populations. `backend/codeatlas/contracts.py` adds `SourceEvidence`, `Symbol`, `Relationship`, `EndpointDeclaration`, `ExploratoryStatistics`, `StructuralAnalysis`, and `DependencyGraph` under schema version 1.0 with analyzer version `phase2-v1`. Every structural record points to its snapshot/file/path and half-open Unicode line/column span. Documentation evidence links symbols to existing extracted docstrings/JavaDoc when matched.

`backend/codeatlas/models.py` and Alembic revision `0002_phase_two` add indexed `analysis_symbols` and `analysis_relationships` tables with FKs to snapshots/jobs/files. The analysis job also stores the complete versioned JSON result atomically with its complete status. Jobs are identified by snapshot, kind and parameters; rows are inserted only on first successful completion. PostgreSQL row locks serialize duplicate delivery. The existing Phase I CAIR response and endpoints remain compatible.

API additions: `POST /api/v1/snapshots/{snapshot_id}/analysis` (202 job; may return 409 while preprocessing runs), `GET /api/v1/jobs/{job_id}/analysis`, `/overview`, and `/graph`. The overview contains language, token, identifier, documentation, structural and dependency tables. The graph contains source-linked symbols and typed edges. OpenAPI was regenerated and the real `frontend/src/data/api.ts` adapter gained typed Phase II methods. The M1 mock adapter returns an explicit `mock_only` error for processing calls.

Supported route declarations: literal FastAPI paths on a top-level `FastAPI`/`APIRouter` instance and Spring `GetMapping`/`PostMapping`/`PutMapping`/`PatchMapping`/`DeleteMapping` literal paths when the Spring annotation package is imported. Dynamic routes are not invented. Java annotations and Python decorators are retained textually on symbols.

Security and correctness limits: no imported source runs; missing or ambiguous relationships are explicit; Python AST failures preserve lexical evidence; Java Tree-sitter recovery is marked partial. Java type resolution, dynamic call dispatch, Python wildcard import binding, and transitive dependencies are not implemented. Some valid syntactic variants are outside this conservative subset; see final verification.
